# Commercial Scan-to-BIM software and startups (as of Nov 2026): automation level, outputs, pricing, documented time savings

> Method note for the report writer: research done 2 Nov 2026. WebFetch was blocked by the session network policy for vendor domains (clearedge3d.com, matterport.com, movingatoms.ai failed DNS), so **all findings below come from search-engine excerpts of the cited pages, not full-page reads**. Numbers are quoted as the excerpts gave them. Almost every speed/accuracy figure is **vendor-reported**; the few independent or academic figures are flagged as such.

## 1. Established tools: what each automates, outputs, and current status

### Takeaway
No established vendor ships a "push-button" point-cloud-to-LOD300 Revit model. The incumbents fall into three tiers. (a) **Real feature extraction to native Revit families**: ClearEdge3D EdgeWise (pipes, ducts, conduit, steel, walls) and Trimble RealWorks (pipes only). (b) **Assisted fitting inside Revit**: Leica CloudWorx, FARO As-Built for Revit, PointCab 4Revit, Undet. (c) **Classification, mesh or visualization upstream of modeling**: Leica Cyclone 3DR / Hexagon GeoCloud, ReCap Pro 2026, Pointfuse, Bentley iTwin Capture, Cintoo, NavVis IVION. MEP pipe extraction is the most mature automation. Architectural walls are the next most mature, and doors/windows/equipment are still largely manual or semi-assisted.

**Autodesk ReCap Pro 2026 + Revit**
- ReCap Pro 2026 (announced 2 Apr 2025) adds **scan-to-mesh**: it converts point clouds into *segmented meshes* on the local machine, with a Mesh Editor for refining and exporting. Processing is local, with no cloud upload. — [Autodesk AEC blog](https://www.autodesk.com/blogs/aec/2025/04/02/whats-new-in-recap-pro-2026/); [Autodesk ReCap features](https://www.autodesk.com/uk/products/recap/features); [Informed Infrastructure](https://informedinfrastructure.com/post/whats-new-in-recap-pro-2026-faster-collaboration-better-coordination-and-efficient-modeling)
- A Revit plug-in places those mesh objects into Revit projects as **Revit Families** (described by a third party as "one-click" mesh-to-family). Unclassified mesh elements cause conversion failures, and scans must be registered and cleaned first. — [Hagerman](https://www.hagerman.com/software/recap-pro); [Desapex](https://www.desapex.com/blogs/recap-2026-how-autodesks-meshing-revolution-will-reshape-the-scan-to-bim-landscape); [Arkance Revit tip](https://ukcommunity.arkance.world/hc/en-us/articles/27489706780306-Revit-Tip-Unable-to-Convert-ReCap-Mesh-Elements-to-Revit-Families)

**Leica (Hexagon): Cyclone 3DR, CloudWorx for Revit, GeoCloud**
- Cyclone 3DR has GPU **AI auto-classification**. The 2025.2 release updated two classification models. The 15 Dec 2025 build lists a "Plant" model v2.0 and a "Heavy construction UAV" model v2.0. The 2025.2 build supports RTX cards with CUDA 12.8, while 2024.1 required CUDA 11.8. — [Cyclone 3DR 2025.2 release notes](https://rcdocs.leica-geosystems.com/cyclone-3dr/2026.1/2025-2-0-cyclone-3dr-release-notes); [Cyclone 3DR downloads](https://cyclone3dr.com/downloads.php); [2024.1.2 release notes](https://cyclone3dr.leica-geosystems.com/download/Cyclone3DRVersion2024.1/ReleaseNotes/Leica%20Cyclone%203DR%202024.1.2%20REL.pdf)
- Classification is saved and exchanged via LGSx, E57, LAS and LAZ. Leica's recommended Scan-to-BIM use is to send an LGSx holding only classes of interest (walls, windows, doors, slabs, columns, beams) to **CloudWorx for Revit**. Classification cleans the point cloud; it does not create Revit objects. — [Leica AI classification article](https://leica-geosystems.com/en-us/products/laser-scanners/software/leica-cyclone/leica-cyclone-3dr/ai-classification-in-leica-cyclone-3dr-pt1); [2024.1.2 notes](https://cyclone3dr.leica-geosystems.com/download/Cyclone3DRVersion2024.1/ReleaseNotes/Leica%20Cyclone%203DR%202024.1.2%20REL.pdf)
- The latest Cyclone 3DR is **2026.1** (build 2026.1.5.50573, 7 Oct 2026). Update 2026.1.1 added **COE export for Scan-to-Steel**. RVT is supported as import, and IFC/COE as export. Leica's stated roadmap is "better Scan-to-Pipe modelling and new Scan-to-Steel functionality." — [Cyclone 3DR downloads](https://cyclone3dr.com/downloads.php); [2026.0.1 release notes](https://rcdocs.leica-geosystems.com/cyclone-3dr/2026.1/2026-0-1-cyclone-3dr-release-notes); [Leica Cyclone 3DR page](https://leica-geosystems.com/products/laser-scanners/software/leica-cyclone/leica-cyclone-3dr)
- CloudWorx for Revit is assisted, not automatic. It offers fitting of steel, flanges, pipes and 2D lines; "placement" of walls, floors, structural members, doors, windows and mechanical equipment; automatic detection of **pipe/round-duct/column centerline and diameter**; and modeling of out-of-plumb walls. It reads point clouds from any scanner. — [Leica CloudWorx for Revit](https://leica-geosystems.com/products/laser-scanners/software/leica-cloudworx/leica-cloudworx-revit); [CloudWorx datasheet](https://leica-geosystems.com/-/media/files/leicageosystems/products/datasheets/leica_cloudworx_for_revit_ds.ashx?la=en)
- HxDR Reality Cloud Studio has been renamed **Hexagon GeoCloud**. It adds cloud AI classification that can "identify, color-code and hide non-essential elements" for Scan-to-BIM and Scan-vs-BIM, streamed directly to CloudWorx or Cyclone 3DR. The exact release date was not confirmed. — [Hexagon GeoCloud newsletter](https://geocloud.hexagon.com/resource/newsletter/hxdr-reality-cloud-studio-feature-highlights-are-here/); [GeoCloud Q2 release webinar](https://geocloud.hexagon.com/resource/webinar/hxdr-reality-cloud-studio-q2-release/)

**BricsCAD BIM (adjacent)**
- BIMIFY classifies existing 3D solids; it does not convert point clouds. Point-cloud steps (floor/room detection, POINTCLOUDFITPLANAR) are semi-automatic and produce solids that BIMIFY then classifies. A Bricsys-partner blog states that automatic BIM from point clouds "is not possible with current technologies, except with very simple models" (dated). — [Bricsys help](https://help.bricsys.com/en-us/document/bricscad-bim/design-documentation/working-with-point-clouds-in-bim); [Octave blog](https://bricscad.octave.com/blog/point-clouds-6-scan-to-bim)

### Inferences
- For Spybee-type construction progress/as-built work, the only incumbent product with **automatic** extraction to native Revit families across several categories is EdgeWise (Pro). Leica/FARO/PointCab/Undet speed up a human modeler inside Revit but don't model unattended.
- ReCap Pro 2026's mesh-to-family is a visual/coordination aid. A mesh family is not a parametric Revit wall, floor or pipe, so it doesn't count as Scan-to-BIM at LOD 300.
- The incumbents are consolidating under hardware OEMs (Topcon–ClearEdge3D, Hexagon–Leica/Avvir, AMETEK–FARO, CoStar–Matterport). Their software roadmaps tend to favor their own scanners and ecosystems.
- Leica's investment focus (Scan-to-Pipe, Scan-to-Steel, COE export) and Trimble's pipe/beam tools confirm that **industrial MEP and steel** automation is ahead of architectural automation among incumbents.

### Gaps
- Full EdgeWise 2025/2026 release notes (e.g., AI features, door/window extraction) could not be read because clearedge3d.com was blocked. Pro/"Premium" pricing is quote-only.
- No current confirmation of FARO As-Built for Revit support for Revit 2025/2026 after the AMETEK acquisition.
- Arena4D (Veesus) and Geomagic: no relevant Scan-to-BIM info found. Geomagic Design X targets mechanical CAD (SolidWorks, NX, Inventor), not Revit — [Optics-Trade](https://www.optics-trade.eu/en/geomagic-design-x.html). Arena4D status is unverified.
- How Matterport's BIM files are actually produced (AI vs. a modeling partner) and whether CoStar changed the offering in 2025–2026 were not confirmed.
- Matterport "Property Intelligence" pricing and BIM-relevant scope were not found in official sources.

## 2. AI-native startups and new entrants (2022–2026): do they exist and what do they actually do?

### Takeaway
The 2024–2026 wave of entrants splits into: (a) **AI-assisted Revit plug-ins** (Aurivus, XGRIDS LCC for Revit) that propose elements a modeler confirms; (b) **"AI + human" conversion services** priced per area with 48 h to days turnaround (IPX BIMIT, ScanToBIM AI, Moving Atoms, ScanToBIM-CAD); (c) **classification/segmentation platforms** (Pointly, Vercator, Cintoo AI); and (d) **progress-tracking/scan-vs-BIM** companies (Avvir, Doxel, Buildots), which are *not* Scan-to-BIM authoring tools. None publishes independently validated accuracy. A services-side critic states that no 2026 AI tool produces LOD 300+ output that passes QA without significant human work.

### Cited Findings

**Aurivus (Germany): AI-assisted Revit plug-in (exists, active)**
- Workflow: the user uploads E57 or ReCap RCP to the portal (app.aurivus.com). AI processing takes about 30 min depending on size and returns a ".aurivus" file of pre-segmented objects, which the Revit plug-in loads. — [Aurivus Getting Started](https://aurivus.com/getting-started/); [Aurivus FAQ](https://aurivus.com/faq/)
- Detects pipes, trusses, stairways, walls, windows, doors and roofs. It detects floors to set levels automatically and places windows/doors from the Revit library. — [Aurivus Architecture](https://aurivus.com/industries/architecture-2/); [Aurivus](https://aurivus.com/)
- Positioned as "manual modeling combined with AI", with the user keeping control. Vendor claims **25–50% modeling time saved**. A reviewer notes no published accuracy metrics. — [Aurivus faster workflow](https://aurivus.com/faster-workflow/); [DataDrivenAEC review](https://datadrivenaec.com/tools/aurivus)
- Also markets a railway-infrastructure point-cloud-in-Revit workflow. — [Aurivus railway](https://aurivus.com/railway-infrastructure-ai-for-point-clouds-in-revit/)

**XGRIDS "LCC for Revit": Gaussian-splatting-based Scan-to-BIM (launched May 2025)**
- Debuted at Autodesk DevCon Europe (21 May 2025). It brings SLAM-based 3D Gaussian Splatting from XGRIDS Lixel scanners into Revit, and AI proposes **levels, walls, doors and windows** as editable Revit elements. — [Engineering.com](https://www.engineering.com/xgrids-debuts-ai-powered-3dgs-scan-to-bim-plug-in-for-revit/); [Yahoo Finance / PR](https://finance.yahoo.com/news/industry-first-xgrids-debuts-ai-142200859.html); [AEC Magazine](https://aecmag.com/news/ai-tool-transforms-gaussian-splats-into-revit-models-lcc-for-revit/)
- Vendor claims are **70–90% modeling-time reduction** and about **3 cm accuracy**. LiDAR provides absolute geometry and splats provide texture/ML context. It syncs live with the LCC Viewer. Announced for Revit 2025+ via the Autodesk App Store by end of May 2025 (go-live not confirmed). No price published. — [Radiance Fields](https://radiancefields.com/xgrids-releases-gaussian-splatting-revit-plugin); [AEC Magazine](https://aecmag.com/news/ai-tool-transforms-gaussian-splats-into-revit-models-lcc-for-revit/); [XGRIDS LCC](https://www.xgrids.com/intl/lcc)

**Moving Atoms (YC S26): AI-plus-service, Gaussian-splat reconstruction (new 2026 entrant)**
- A Y Combinator Summer 2026 company. Pitch: "Send a LiDAR or SLAM scan from any scanner. Within **48 hours** every object comes back separated, measured and editable, in IFC, Revit, STEP, USD or GLB." It targets data centers, digital twins and "SimReady" worlds. — [Moving Atoms on X](https://x.com/MovingAtomsLab/status/2110189078511845778); [Moving Atoms about](https://movingatoms.ai/about/)
- The pipeline reconstructs the raw scan (e.g., 54M points) as a photoreal Gaussian splat, then builds every pipe, fitting, valve and steel member as a native object. Stated LOD 200–500. Inputs are E57, LAS/LAZ, PLY, RCP/RCS, FARO, Leica, NavVis, RIEGL, XGRIDS, up to 200 GB/file. — [Moving Atoms on X](https://x.com/MovingAtomsLab/status/2113543323692519814); [Moving Atoms Scan to BIM](https://movingatoms.ai/scan-to-bim/)
- Example claim: a NavVis VLX 3 scan turned into **1,231 Revit objects**, delivered as Revit 2025 + IFC. Pricing is quote-based via founder call. — [Moving Atoms](https://movingatoms.ai/)

**ScanToBIM AI (scantobim-ai.com): per-area AI service**
- Returns IFC, native Revit and AutoCAD files plus a QA report. **USD 0.18/sq ft** (about USD 1.94/m²) for LOD 300 architecture, billed per scan by modeled area, with "no software seats, no subscriptions." — [ScanToBIM AI](https://www.scantobim-ai.com/)

**ScanToBIM-CAD (thescantobim.com): browser-based, low-cost**

**Reality check**
- "No AI tool in 2026 produces LOD 300+ output that passes professional QA without significant human intervention." ### Inferences
- The fastest-growing commercial model is **"AI engine + human QA sold per m²/ft²"** (IPX, ScanToBIM AI, Moving Atoms, Matterport), not self-serve software. This suggests vendors themselves don't trust unattended output enough to sell it as a tool.

- Doxel/Buildots/Avvir solve **scan-vs-BIM progress** (which presupposes an existing design BIM), not scan-to-BIM. They are the relevant comparators if Spybee's use case is progress verification rather than as-built authoring.

### Gaps
- **Struxi, Hyperdrive, Mosaic, Disperse, Plannerly**: searches returned no evidence of a point-cloud-to-BIM product under these names. Their existence or relevance is **unverified**. (Disperse and Mosaic may be progress-tracking/capture companies, but this was not confirmed in this research.)
- Aurivus pricing and funding: not found. XGRIDS LCC for Revit pricing: not found. Moving Atoms pricing: quote-only.
- No independent benchmark compares any of the AI entrants on the same dataset.

## 4. Documented case studies with before/after time

### Takeaway
The only quasi-independent quantified evidence is academic and concerns **pipe modeling with EdgeWise: about 64–67% of man-hours saved** (University of Cambridge state-of-practice study). Every other before/after figure is vendor or customer marketing, ranging from 30% faster to 80% saved, or "8 weeks manual" vs. a fraction. No credible "6 weeks to 3 days" architectural case with full methodology was found.

### Cited Findings
- **Academic (Cambridge):** "67% of pipe modelling time is saved by EdgeWise" compared with Revit, and 64% of man-hours for cylinder modeling vs. conventional modeling. — [University of Cambridge repository: State-of-practice on As-Is Modelling of Industrial Facilities](https://www.repository.cam.ac.uk/bitstreams/6830a483-a203-49ec-a362-fa8eecbfeb3e/download)
- **Vendor case, industrial (EdgeWise Pro + OmniSLAM R8+):** an industrial facility was modeled to native Revit in about **14 hours**, with **889 straight pipe segments auto-extracted**. The vendor caveats that noisy data shifts work back to the modeler. — [ClearEdge3D blog](https://www.clearedge3d.com/blogs/how-edgewise-pro-and-the-omnislam-r8-turned-an-industrial-point-cloud-into-a-native-revit-model-in-14-hours/)
- **Customer quotes (vendor-published):** "EdgeWise saved us over 240 man-hours on a recent modeling project" (OR3D). ENG modeled MEP "30% faster" on a large gas-reservoir project. One team's MEP + structure took 25 h in EdgeWise, "a time savings of about 40 hours" (about 62% saved). For Brandt's underground piping, the manual process was estimated at **8 weeks**, with **about 80% time saved**. — [ClearEdge3D ENG case](https://www.clearedge3d.com/edgewise/eng-reduces-mep-modeling-with-edgewise-in-huge-gas-reservoir-bim-project/); [EdgeWise MEP](https://new.clearedge3d.com/edgewise/mep-modeling/); [SolidCAD MEP brochure](https://www.solidcad.ca/wp-content/uploads/2017/10/EW-MEP-Brochure.pdf); [xyHt "Piping Hot Tech"](https://www.xyht.com/bim/piping-hot-tech/)
- **Architecture/office (Autodesk University class):** automatic extraction of walls, columns and levels in EdgeWise cut Revit modeling time by **50–70%** on an office project (presenter's own project, vendor-adjacent). The same figure is repeated in a Politecnico di Milano thesis. — [Autodesk University 2021](https://www.autodesk.com/autodesk-university/article/Refining-Scan-BIM-Workflow-Further-Automation-and-Visualization-2021); [PoliMi thesis](https://www.politesi.polimi.it/bitstream/10589/177607/1/BRUMATTI%20PINHO%20LETICIA%2010665567.pdf)
- **Scan-vs-BIM (not authoring):** a deep-learning steel-frame comparison finished in about 3 min, a >95% processing-time reduction. — [ScienceDirect, Automation in Construction](https://www.sciencedirect.com/science/article/abs/pii/S0926580524006678)
- **Open-source benchmark:** Cloud2BIM runs the full pipeline to IFC in 60 s on the ETH synth3 dataset, vs. 359 s for a 2019 method without IFC export. These are compute times, not modeler hours. — [arXiv 2503.11498](https://arxiv.org/abs/2503.11498)
- **Counterpoint:** a 2025 Dynamo-based scan-to-BIM study found manual steps "remain time-consuming", which highlights the need for more automation. — [zfv 2025/5, Volland et al.](https://geodaesie.info/images/zfv/150-jahrgang-2025/downloads/zfv_2025_5_Volland_et-al.pdf)
- **New-entrant claims (vendor):** XGRIDS 70–90%, Aurivus 25–50%, NavVis customer about 10%, ScanToBIM ML tool up to 50%. — [AEC Magazine](https://aecmag.com/news/ai-tool-transforms-gaussian-splats-into-revit-models-lcc-for-revit/); [Aurivus](https://aurivus.com/faster-workflow/); [NavVis](https://www.navvis.com/ivion/scan-to-bim); [DataDrivenAEC](https://datadrivenaec.com/tools/scantobim)
- **Turnaround framing:** Moving Atoms contrasts its 48 h with manual Scan-to-BIM "usually quoted in weeks because a modeler traces each element by hand". — [Moving Atoms](https://movingatoms.ai/scan-to-bim/)

### Inferences
- A defensible planning assumption for a report is **about 50–70% modeler-hour reduction for MEP/pipe-heavy and simple orthogonal architecture** when using mature feature extraction (EdgeWise class). Expect much less (10–30%) for cluttered or occupied interiors and for tools that only classify or align.
- Vendor claims have trended upward over time (70% to 85% for MEP, then 70–90% for XGRIDS), but there is no independent replication of the higher numbers.

### Gaps
- No independent, peer-reviewed before/after study for any 2024–2026 AI entrant (Aurivus, XGRIDS, IPX, Moving Atoms).
- No published case with full context (m², LOD, scanner, team size) of the form "6 weeks to 3 days" for architecture. Full EdgeWise case-study pages could not be fetched.

Traditional and offshore shops still quote days to weeks, and their internal tooling (e.g., EdgeWise use) is not publicly documented.

### Cited Findings
- **IPX (Integrated Projects):** proprietary BIMIT engine with tiered automation (BIMIT 100 fully automated at USD 0.04/ft² in hours; BIMIT 300 architect-reviewed LOD 300 from USD 0.27/ft² in days). ### Gaps

## 6. Integration options for an automated pipeline (Revit API/Dynamo, IFC/IfcOpenShell, Speckle, APS Design Automation)

### Takeaway
A fully automated, headless pipeline is technically feasible with **open-source segmentation → IfcOpenShell (IFC) → optional APS Design Automation for Revit (headless Revit in the cloud) to convert or enrich into RVT**. None of the commercial desktop tools (EdgeWise, CloudWorx, Cyclone 3DR, FARO, PointCab) document a public automation API, and most need a desktop GPU or a licensed local Revit. Point-cloud access inside Revit is API-capped (1M points per `GetPoints` call), so point processing should happen *outside* Revit.

### Cited Findings
- **APS Design Automation for Revit** provides "a headless version of Revit running in the cloud". It can create, extract and modify Revit data, and supports both non-workshared and workshared Revit cloud models (ACC/BIM 360). The Automation API engines are AutoCAD, 3ds Max, Inventor, Revit and Fusion. — [APS Design Automation overview](https://aps.autodesk.com/en/docs/design-automation/v3/developers_guide/overview); [DA Revit release notes](https://aps.autodesk.com/en/docs/design-automation/v3/change_history/revit_release_notes)
- Autodesk publishes a sample **MCP server** that lets AI assistants drive Revit through the Automation API with server-to-server auth ("headless, scalable automation of Revit operations on cloud-hosted models"). A third-party Python SDK (VIKTOR) wraps the Automation API, with examples for IFC export and parameter edits. — [APS sample MCP server](https://github.com/autodesk-platform-services/aps-sample-mcp-server-revit-automation); [VIKTOR aps-automation-sdk](https://github.com/viktor-platform/aps-automation-sdk)
- **Revit API point-cloud limits:** `PointCloudInstance.GetPoints` accepts 1 to 1,000,000 points per call, and results may not be consistent between repeated calls when more points pass the filter. An unofficial Rhino.Inside developer attributes the ~1M cap to Revit's point-cloud libraries. — [Revit 2026 API docs](https://apidocs.co/apps/revit/2026/6761fd71-e38e-d60f-90f7-9e034bf2d5c0.htm); [McNeel forum](https://discourse.mcneel.com/t/rhino-inside-pointclouds/86881)
- **IFC via IfcOpenShell (open source):** Cloud2BIM (Czech Technical University authors Zbirovský & Nežerka) segments slabs (density histogram), splits storeys, extracts walls from 2D sections, detects openings and zones rooms, then writes **IFC 2x3** (slabs, walls, openings, spaces) with IfcOpenShell. Inputs are E57/XYZ, plus LAS/LAZ in a fork that also adds installers and a web IFC viewer. — [arXiv 2503.11498](https://arxiv.org/abs/2503.11498); [Cloud2BIM v1.02 release](https://github.com/VaclavNezerka/Cloud2BIM/releases/tag/v1.02); [pintorus/Cloud2BIM fork](https://github.com/pintorus/Cloud2BIM)
- Another research codebase does "fully automated scan-to-BIM via point cloud instance segmentation". — [LTTM/Scan-to-BIM GitHub](https://github.com/LTTM/Scan-to-BIM)
- **Commercial SDK option:** the ODA Scan-to-BIM SDK (semantic segmentation to IFC) is the only vendor SDK found that is explicitly built for embedding. — [ODA Scan-to-BIM SDK](https://www.opendesign.com/products/scan-to-bim)
- **Vendor connectors (not APIs):** Cintoo4Revit, the NavVis Revit add-in / Qbitec streaming, the Matterport Revit plug-in and the Hexagon GeoCloud stream to CloudWorx/Cyclone 3DR are all interactive integrations. Trimble RealWorks "Send to Revit" requires a locally installed, licensed Revit. — [Cintoo4Revit](https://help.cintoo.com/en/support/solutions/articles/101000550009-cintoo4revit-plugin); [NavVis Revit](https://www.navvis.com/integrations/autodesk/revit); [Matterport for Revit](https://apps.autodesk.com/RVT/en/Detail/Index?id=6762901765784290868&appLang=en&os=Win64); [Hexagon GeoCloud](https://geocloud.hexagon.com/resource/newsletter/hxdr-reality-cloud-studio-feature-highlights-are-here/); [RealWorks 12.3](https://help.fieldsystems.trimble.com/realworks/12.3.htm)
- **Bentley iTwin Capture Cloud Services** offers cloud AI feature extraction and classification that Manage & Extract consumes alongside cloud BIM. It is the incumbent closest to a cloud API for classification, but it does not output BIM objects. — [Bentley iTwin Capture Cloud Services](https://www.bentley.com/software/itwin-capture-cloud-services/)

### Inferences
- Recommended architecture for a custom pipeline: (1) register and subsample outside Revit (e.g., PDAL/Open3D-class tools); (2) run ML segmentation (Cloud2BIM-style heuristics or an instance-segmentation model); (3) write IFC4/IFC2x3 with IfcOpenShell; (4) optionally run a Design Automation for Revit job that loads parameters (wall lines, heights, openings as JSON) and creates **native** Revit walls, floors and families, which is more robust than importing IFC into Revit. Speckle could serve as the transport between steps, but this research did not confirm a Speckle point-cloud or Scan-to-BIM connector.
- Commercial desktop tools (EdgeWise, CloudWorx, FARO, PointCab) are hard to embed in an unattended cloud pipeline. They lack documented APIs and need a GPU, a local Revit, or both. They fit a "human-in-the-loop accelerator" role rather than a backend.

### Gaps
- Whether Revit point-cloud APIs (RCP linking, `GetPoints`) are available inside the Design Automation engine is undocumented. This needs a direct test or Autodesk confirmation.
- No evidence was found of a **Speckle** Scan-to-BIM connector or of public REST APIs for EdgeWise, Aurivus, XGRIDS LCC or Moving Atoms. IPX/ScanToBIM AI may offer upload APIs, but this wasn't confirmed.
- Dynamo-based Scan-to-BIM automation is referenced only via the 2025 zfv study; no maintained commercial Dynamo package for auto-modeling from point clouds was found.
